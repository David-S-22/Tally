# The Bills tests Sophia-CI runs. conftest.py marks every other test `extended`,
# so `-m "not extended"` is this list and `-m extended` is the rest (run both
# before a release). One test per behaviour or route, plus one representative
# case of each parametrized sweep. `file::test` keeps every case of a
# parametrized test; `file::test[id]` keeps one. A line that stops matching a
# test fails collection, so renaming a core test means renaming it here too.
